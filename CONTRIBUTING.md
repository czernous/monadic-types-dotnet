# Contribution Policy

MonadicTypes.NET is a maintainer-directed, deliberately bounded project. External
pull requests and feature requests are not currently accepted. Please fork the
Apache-2.0-licensed code when a different scope or API is required.

Correctness, security, NativeAOT compatibility, performance-regression, and
documentation defects may be reported for maintainer review. A report should
include a minimal reproduction, target framework and runtime, operating system,
and measured evidence where performance is involved. Reporting a defect does not
create a support commitment or guarantee a fix.

Intentionally submitted material is governed by section 5 of the Apache License
2.0 unless it is conspicuously marked `Not a Contribution`.
